# 語音輸入（Voice Input）

**繁體中文** ｜ [English](README.md)

在任何 Windows 應用程式裡，用說話取代打字——完全在你自己的電腦上執行，不用連網、也不會把你的聲音送到雲端（第一次安裝時下載模型那次除外）。辨識引擎是 **Qwen3-ASR-1.7B**，具備原生標點並會自動簡轉繁。

## 這是什麼＋一分鐘上手

安裝好之後，「語音輸入」會安靜地待在工作列（螢幕右下角）的小圖示裡。不管你人在 LINE、瀏覽器網址列、Word，還是任何看得到游標在閃的地方，都可以直接用講的輸入文字：中文會自動變成有標點的繁體中文，句子裡夾雜的英文術語（例如 API、benchmark）也會維持正確拼寫。

核心操作只有一個動作：

1. **按住 CapsLock 鍵**（左上角「大小寫鎖定」那顆鍵）開始說話——螢幕角落會出現一個小小的錄音提示，同時有提示音（可在設定裡關掉）
2. **放開** → 稍等一下，辨識出來的文字就會自動貼到游標所在的位置
3. 只是想切換大小寫的話，跟平常一樣「輕點一下」CapsLock 就好；只有「按住不放」才會觸發錄音，兩種用法不會互相干擾

就這樣，沒有其他步驟。

## 執行需求

| | |
|---|---|
| 作業系統 | Windows 10 或 11 |
| Python | 必須是 3.12。`setup.bat` 會擋掉其他版本，不會硬建一個裝到一半才出錯的環境 |
| 顯示卡 | **必須有 NVIDIA 顯示卡與正常的驅動程式。** 辨識在 GPU 上執行，沒有可用的 CUDA 裝置就無法運作 |
| 硬碟空間 | 約 4GB。第一次執行會下載約 3.6GB 的模型與執行元件 |

顯示卡這條不是「建議」而是「必須」：內建的 llama-server 是 CUDA 版本，另一顆 Breeze 引擎也指定要 CUDA 裝置，所以沒有 NVIDIA 顯示卡的電腦沒有任何可用的退路。首次執行精靈會先檢查，不符合就直接停在那一步，不會讓你先下載好幾 GB 才失敗。

## 安裝與啟動

### 第一次安裝（只需要做一次）

1. **雙擊 `setup.bat`**
   會跳出一個黑底文字視窗開始跑，這是在幫你建立一個獨立的 Python 執行環境並安裝所需套件，過程中請保持網路連線。看到「Setup complete」就是成功了，按任意鍵關閉視窗即可。
2. **雙擊 `啟動語音輸入.vbs`** 啟動工具
   跟 `setup.bat` 不同，這個檔案啟動時**不會**跳出任何視窗，只會安安靜靜地在工作列出現一個小圖示。以後要用，都用這個檔案啟動（或看下面做一個桌面捷徑）。

### 想要桌面捷徑？

如果不想每次都跑到專案資料夾找 `啟動語音輸入.vbs`，可以建一個桌面捷徑：在專案資料夾空白處按住 **Shift 鍵再按右鍵**，選單裡選「在這裡開啟 PowerShell 視窗」（部分版本會顯示成「在終端機中開啟」或「在此處開啟命令視窗」，是同樣的東西），貼上以下指令後按 Enter：

```
.venv\Scripts\python scripts\make_shortcut.py
```

桌面就會出現一個「語音輸入」的捷徑，之後雙擊它，效果跟雙擊 `啟動語音輸入.vbs` 完全一樣。

### 首次啟動精靈

**第一次**啟動時，會自動跳出一個小視窗，帶你完成三個步驟：

1. **硬體檢查**：確認有沒有可用的 NVIDIA 顯示卡。**沒有的話會停在這一步**——這是必要條件，不是效能選項。這個畫面本身要靠 Windows 內建的 WebView2 元件才能顯示，一般 Windows 10／11 都已內建，通常不用額外處理。
2. **下載辨識模型**：預設引擎 Qwen3-ASR-1.7B、llama-server 執行元件與語音偵測模型都會一併下載，合計約 3.6GB；需要網路連線，依網速可能要幾分鐘，請耐心等待、不要中途關閉視窗。
3. **麥克風測試**：按一下按鈕、講幾句話，確認電腦有收到你的聲音。

三步驟都完成後就大功告成，之後每次啟動都不會再看到這個精靈——只會在工作列看到常駐圖示，照「一分鐘上手」的方式直接使用即可。

## 設定視窗說明

工作列上的圖示：**左鍵點一下**打開設定視窗；**右鍵點一下**彈出選單，可以「暫停辨識／恢復辨識」「開啟設定」「結束」。

設定視窗裡有 5 個分頁：

| 分頁 | 用途 |
|---|---|
| **一般** | 開機自動啟動、提示音開關、貼上方式、原樣輸出、中文數字轉阿拉伯數字（「四零九六」→ 4096、「十二GB」→ 12GB）、短句免標點、選擇要用哪個麥克風裝置 |
| **熱鍵** | 更改觸發錄音的按鍵、調整「按多久才算長按（開始錄音）」的門檻 |
| **模型** | 切換辨識引擎，或下載尚未安裝的引擎 |
| **熱詞** | 自訂「常被聽錯的詞」修正規則 |
| **歷史** | 查看最近 200 筆辨識紀錄 |

### 關於 Breeze-ASR-25（已標記淘汰）

除了預設的 Qwen3，本工具還有第二顆引擎 Breeze-ASR-25，但它**已標記為淘汰、預計 v1.2 移除，預設也不再安裝**。

原因是實際使用下來 Qwen3 的辨識品質明顯較好，而 Breeze 會多帶進約 1GB 的依賴套件（CTranslate2、cuDNN 8，還有一個為了它而鎖死的舊版 `setuptools`，那個鎖會擋住未來的 Python 版本升級）——這些東西 Qwen3 一個都用不到。

如果你還是想試試看，先安裝它的額外依賴，再從「模型」分頁下載：

```
.venv\Scripts\pip install -r requirements-breeze.txt
```

### 熱詞規則怎麼寫？

在「熱詞」分頁裡，一行一條規則，格式是：

```
誤辨詞=正確詞
```

- `#` 開頭的整行當作註解，不會生效
- 例如常講的 Python 常被聽成「派森」，就加一行：

```
派森=Python
```

存檔後立刻生效，不用重開程式。

## 疑難排解

**在某些視窗裡貼不進去**
如果目標視窗是「以系統管理員身分執行」的（例如某些系統工具），本工具會因為 Windows 的權限機制而貼不進去——這是 Windows 本身的限制，不是故障。這種情況下文字其實已經在剪貼簿裡了，兩個解法擇一即可：
- 手動按 `Ctrl+V` 貼上
- 改用「以系統管理員身分執行」啟動本工具

**首次執行精靈說「找不到 NVIDIA 驅動程式」**
精靈是透過 NVIDIA 驅動程式（`nvcuda.dll`）確認有沒有可用的 CUDA 裝置，找不到就會停下來。請到 [NVIDIA 官方驅動程式下載頁](https://www.nvidia.com/Download/index.aspx) 安裝或更新驅動程式，再重新開啟視窗。如果你確定電腦有 NVIDIA 顯示卡卻仍出現這個訊息，通常是驅動程式安裝不完整，重新安裝一次即可。

**出現 cuDNN／CUDA 之類的顯示卡錯誤**
先確認顯示卡驅動程式是最新版本；如果還是不行，重新執行一次 `setup.bat` 通常能解決。

**剛啟動、講第一句話時反應比較慢**
顯示卡如果閒置一段時間會自動降頻休眠，第一句話多花 0.1～0.3 秒才出字是正常現象，講下一句就會恢復正常速度。

## 剪貼簿小提醒

貼上文字的那一瞬間，工具會短暫「借用」一下你的剪貼簿，貼完後會自動把你原本複製的內容還原回去——不只文字，**圖片、檔案、帶格式的文字（Word／網頁內容）都會原樣還原**，畫質與內容完全不變。

剪貼簿的實際讀寫由一個獨立的小幫手行程代辦：就算防毒軟體等監控程式與剪貼簿操作起衝突，受影響的也只是小幫手（會自動重生），主程式與貼上結果不受波及。

少數例外：某些程式的「進階貼上狀態」無法保留——例如 Excel 複製後的虛線框（再按 Ctrl+V 貼公式連結那種）會被取消。這是 Windows 剪貼簿一經任何變動就會發生的行為，並非本工具特有。
