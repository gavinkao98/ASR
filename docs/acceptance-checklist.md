# 驗收清單
- [ ] 純中文句：「今天下午三點開會，記得帶筆電。」→ 繁體、有標點
- [ ] 中英夾雜：「我用 faster whisper 跑 ASR 的 benchmark。」→ 英文術語拼寫正確
- [ ] 純英文句：「The quick brown fox jumps over the lazy dog.」
- [ ] 長段落 30 秒口述 → 完整出字、延遲 ≤ 2 秒
- [ ] 延遲體感：3–5 秒短句 → 放開後 1 秒上下出字
- [ ] 熱詞：加一條規則後立即生效
- [ ] 在 LINE / 瀏覽器網址列 / Word 各貼一次成功
- [ ] 短按 CapsLock 大小寫切換正常；長按不觸發大小寫
- [ ] 沒說話按放 → 不貼字只提示
- [ ] 錄音中浮窗與提示音正常；設定中可關提示音
- [ ] 引擎切到 Qwen3 再切回（模型頁下載後）→ 兩顆都能辨識、Qwen3 輸出為台灣正體
- [ ] 歷史分頁看得到紀錄、雙擊可複製、清空有效
- [ ] 開機自啟開啟 → 重開機後托盤自動出現
